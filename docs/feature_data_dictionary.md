# Healthcare Digital Twin
# Longitudinal Feature Data Dictionary

## 1. Purpose

This document defines the longitudinal features generated by the
Healthcare Digital Twin kidney pilot.

The features describe changes in repeated patient observations over time.

They are statistical longitudinal features only.

They do not represent:

- Clinical diagnosis
- Disease staging
- Clinical risk thresholds
- Prognosis
- Treatment recommendations
- Causal relationships

Clinical interpretation and clinical decision rules require validation
and input from the DSC team.

---

# 2. Input Parameters

The current kidney pilot supports the following longitudinal parameters.

| Parameter | Description | Unit | Prototype worsening direction |
|---|---|---|---|
| eGFR | Estimated glomerular filtration rate | mL/min/1.73 m² | Decreasing |
| Creatinine | Serum creatinine | mg/dL | Increasing |
| UACR | Urine albumin-to-creatinine ratio | Project-defined input unit | Increasing |
| Systolic BP | Systolic blood pressure | mmHg | Increasing |
| Diastolic BP | Diastolic blood pressure | mmHg | Increasing |
| HbA1c | Glycated hemoglobin | % | Increasing |

The worsening directions are configurable prototype conventions.

They must not be interpreted as clinical rules without validation.

---

# 3. Feature Availability Rules

The current minimum observation requirements are:

| Feature | Minimum observations |
|---|---:|
| Baseline | 1 |
| Latest | 1 |
| Absolute change | 1 |
| Percentage change | 1 |
| Slope | 2 |
| Average rate | 2 |
| Variability | 2 |
| Trend | 2 |
| Acceleration | 4 |

For slope calculation, observations must occur on distinct dates.

For average rate calculation, valid consecutive observations must have
a positive elapsed time.

Acceleration requires at least four valid observations, producing at
least three valid transition rates.

Missing parameter values are excluded from the calculation for that
parameter.

# 4. Baseline

## Definition

The first valid observation for a parameter after chronological sorting.

## Formula

No mathematical transformation is applied.

baseline = first valid observation
